## Story

**As a** visitor arriving from Instagram (mostly on a mid/low-end phone),
**I want** one elegant page that shows both of Jaya's worlds (Shakti and Jaya AI) and routes me to the right product,
**so that** I reach the right destination in one tap, without friction or a slow page.

## Decisions (approved by Jaya, 2026-09-24)

- Architecture: Astro static site, own Vercel project, zero JS by default.
- Scope: complete (device tiering + shader, JSON-LD, Lighthouse CI budget, links in a data file).
- Domain: `plataforma.jayaroberta.com.br`.
- Command Center and JayaFinance: discreet "Área restrita" link in the footer only.
- Real photos supplied by Jaya in `src/assets/photos/`.

## Acceptance Criteria

1. Page shows a hero (photo, name, positioning line) and two portals, **Shakti** and **Jaya AI**, each listing its destinations from `src/data/links.json`.
2. Links cover: shaktijaya.com.br, Quiz 5 Elementos, Ayla IA, 7 Planners (Hotmart), Fogueira Junina, Claude do Zero (`/claude`), Biblioteca Claude by Jaya, Business Jaya / Primeira Conversa, Atlas de Forças, EIXO, plus Instagram/WhatsApp/YouTube. Command Center and JayaFinance only under footer "Área restrita".
3. Every outbound link carries `utm_source=plataforma&utm_medium=hub&utm_content=<id>`, opens in the same tab and uses no `noreferrer`. *Superseded 2026-09-25 (PRD FR1): outbound links open in a new tab with `rel="noopener"`.*
4. Light and dark themes: follow `prefers-color-scheme` by default, manual toggle persists, no flash of wrong theme; toggle uses a View Transition circular reveal when supported.
5. Motion: headline line reveal, photo clip reveal, scroll-driven card reveals, botanical line drawing, animated sun-glow background. All respect `prefers-reduced-motion` (fade only or static).
6. Device tiering: tier 0 (reduced motion / Save-Data / slow network) gets no animated background; tier 1 gets CSS-only ambient; tier 2 (WebGL2 + ≥4 GB + 4g, no reduced motion) gets the OGL shader, capped at DPR 1.5 / 30 fps, paused offscreen and when the tab is hidden, with context-loss handling.
7. Pointer-only effects (spotlight border, magnetic CTA) are active only on `(hover:hover) and (pointer:fine)`.
8. Performance budget (Lighthouse mobile, enforced by `lighthouserc.json`): performance ≥ 0.95, LCP ≤ 2000 ms, CLS ≤ 0.05, TBT ≤ 150 ms, total JS ≤ 50 KB.
9. Accessibility: AA contrast in both themes, visible `:focus-visible`, touch targets ≥ 44 px, landmarks (`header`, `main`, `nav`, `footer`), Lighthouse accessibility ≥ 0.95.
10. SEO/share: title, description, canonical, OG/Twitter tags with a 1200×630 JPG, JSON-LD `Person` with `sameAs`.
11. Instagram WebView safe: hero uses `svh`/min-height, `viewport-fit=cover` + safe-area insets.
12. Vercel Web Analytics + Speed Insights enabled.
13. Missing photos fall back to generated placeholders; the build never fails because a photo is absent.

## Redesign — SAND (2026-09-25)

Jaya rejected v1 ("extremamente simples e escura"). Rebuilt on the SAND design system (`sanddesignsystem.html`) and the "Atlas de Inteligência — sand" mockup:
- Marcellus + Open Sans 300; paper cream, teal ink, rust action, gold; square UI + circle motif; SAND hover inversion.
- Light is the default regardless of OS; dark ("noite no deserto") is opt-in and remembered.
- Artwork from Jaya's library, curated by `scripts/curate-art.mjs` into `src/assets/art/` (library itself stays local, git-ignored): zona-genialidade 14 (hero), 19 (panorama), 11 (Jaya AI), arcanos-brutos (Shakti cover, 7 planner medallions, tarot fan), `jaya 09` portrait, real Jaya logos (as CSS masks).
- New sections: quick-access cards, Atlas dos 5 Elementos (medallions on a dotted orbit), Tarot da Jaya (`/tarot`, added by Jaya), panorama band, SAND teal footer.
- Perf fixes found during the redesign: WebGL probe + shader deferred to first interaction (was an intermittent 200ms+ long task); hero lede no longer italic (keeps a 50 KB font off the critical path); images `quality` tuned; mask-image replaced by overlay.
- Lighthouse mobile ×5: 99 · 100 · 100 · 100; LCP ~2.05 s, TBT 0, CLS 0. First load ~250 KB. LCP budget in `lighthouserc.json` now errors at 2.5 s (Google "good").
