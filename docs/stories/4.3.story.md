## Story

**As a** visitor on shaktijaya.com.br who just read about the 5 elements,
**I want** to see the seven planners as one constellation, each with its element, theme and price,
**so that** I can open the planner for my element without having to take the quiz first.

## Decisions (Jaya, 2026-09-29)

Prototype approved: https://claude.ai/artifact/HydQibdvVm8bgXqBzFEyLN (format from `capa-planners/3.png`, in the Shakti design system).

1. **Background:** Noite (roxo-noite ground, gold medallions, laranja-claro accents).
2. **Placement:** new section right after Método (`#metodo`), before Blog. `FiveElements` stays untouched.
3. **Quiz highlight:** a visitor who finished the quiz sees "Seu elemento" / "Seu planner" on the recommended medallion.
4. **New tokens** accepted: `--jaya-roxo-noite`, `--despertar(-light)`, `--harmonia(-light)`.
5. **Footer line** accepted for all seven: PDF of 30 days, immediate access through Hotmart, 7-day guarantee.

## Acceptance Criteria

1. `#planners` section renders on the home (pt, en, es) between `#metodo` and `#blog`.
2. Seven medallions in two groups: five elements (Terra, Água, Ar, Fogo, Éter) and "a relação inteira" (Despertar, Harmonia). Each shows number, name, theme, arcano and R$ 57. Names, themes and arcanos match `hub-ecossistema/src/data/links.json`.
3. Medallion art is the center of each planner's light cover (`capa-planners/<slug>-claro.png`), ring in the element color. Images are webp, lazy, with width/height set.
4. Each medallion links to its sales page `https://plataforma.jayaroberta.com.br/planners/<slug>` with UTMs `utm_source=shaktijaya&utm_medium=home&utm_campaign=planner_5elementos&utm_content=<slug>`.
5. Highlight: only when the stored quiz (`quiz-5-elementos-storage`) has a result **and** the email was submitted; the planner comes from `recomendarPlanner` (same source as the quiz CTA). No highlight otherwise. Storage read never throws.
6. Layout: staggered constellation on desktop, two columns on phone (≥ 320px) without horizontal scroll; visible keyboard focus; `prefers-reduced-motion` stops the compass rotation.
7. Copy in pt, en and es in `home.json` (`planners.*`); Portuguese copy passes `revisora`.
8. `npm run lint`, `npm run typecheck` and `npm run test:root` pass; unit tests cover the stored-planner reader.
9. Jaya approves on localhost before any push.

## Dev Notes (2026-09-29)

- The quiz already persists its state (`quiz-5-elementos-storage`, zustand persist), so the highlight needed no quiz change. It reads through `useSyncExternalStore` (server snapshot null, so prerendered HTML never carries a result; a quiz finished in another tab updates it).
- Ring classes are a static map in the component: Tailwind purges `@layer components` classes it cannot see, and `planner-${slug}` was invisible to it.
- The ring color variable is `--planner-ring`, not `--ring` (that one is the shadcn focus token).
- Compass rose hidden below `md`: on phones it sat on top of the Éter medallion.
- Gates: `npm run lint` 0; `npm run test:root` 76/76; `tsc -b`, `typecheck:api`, `typecheck:functions` and dashboard `typecheck` pass. `typecheck:dashboard-server` fails with `TS2688 bun-types` on clean `main` too (package not installed in this worktree), unrelated to this story.
- Browser check on localhost:5188: section between `#metodo` and `#blog`, 7 images load, no horizontal scroll at 390px and 1400px, highlight shows only with result + email.
